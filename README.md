# MCP·Каталог

Русскоязычный каталог MCP-серверов (Model Context Protocol) для российских сервисов — Ozon, Wildberries, Яндекс, 1С, Битрикс24, GigaChat, Т-Банк и др. — плюс популярные мировые серверы.

**Сайт:** https://mcp-katalog.vercel.app

## Что внутри
- `data/servers.json` — датасет (230+ записей): описание на русском, категория, сервис, репозиторий, официальность, звёзды, транспорт, команды установки для Claude Code и Cursor.
- `app/`, `lib/` — сайт на Next.js (static export): поиск, категории, страницы сервисов `/mcp/<service>`, карточки серверов.
- `scripts/` — сбор и обогащение данных (GitHub API, README-парсер команд установки).

## Запуск
```bash
npm install
npm run build   # статика в out/
```

## Добавить сервер
Откройте issue по шаблону «Добавить MCP-сервер» (метка `submission`) или воспользуйтесь формой на сайте: https://mcp-katalog.vercel.app/add/

## Данные
Звёзды и даты — на момент сбора (GitHub API). Записи без готовой команды помечены «установка из исходников». Сведения о совместимости с GigaCode не проверялись.
